# Contracts

## Overview

### Available Operations

* [queryContract](#querycontract) - Query contracts
* [getContract](#getcontract) - Get contract

## queryContract

Use when searching revenue recognition contracts by customer, subscription or contract status. Returns a paginated list.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="queryContract" method="post" path="/contracts/search" -->
```typescript
import { Flexprice } from "@flexprice/sdk";

const flexprice = new Flexprice({
  apiKeyAuth: "<YOUR_API_KEY_HERE>",
});

async function run() {
  const result = await flexprice.contracts.queryContract({});

  console.log(result);
}

run();
```

## getContract

Use when you need to load a single revenue recognition contract with the subscriptions it covers. Contracts are derived from subscriptions and are read-only.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getContract" method="get" path="/contracts/{id}" -->
```typescript
import { Flexprice } from "@flexprice/sdk";

const flexprice = new Flexprice({
  apiKeyAuth: "<YOUR_API_KEY_HERE>",
});

async function run() {
  const result = await flexprice.contracts.getContract("<id>");

  console.log(result);
}

run();
```
